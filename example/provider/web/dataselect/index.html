FDSN DataSelect Service

Example web page for the DataSelect endpoint in the fdsnws-go sample provider.

This page demonstrates a simple English landing page for the FDSN DataSelect service. The example provider can serve MiniSEED-style data for a sample network and station.

Example request

/fdsnws/dataselect/1/query?net=XX&sta=DEMO&loc=00&cha=BHZ&start=2020-01-01T00:00:00&end=2020-01-01T00:00:10

Use this endpoint to request waveform data for a short time window and inspect the response format.
