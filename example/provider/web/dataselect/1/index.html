DataSelect Version 1

This page represents the versioned FDSN DataSelect endpoint for the example provider.

Service notes

  • Requests are made through the /fdsnws/dataselect/1/query path.
  • Use net, sta, loc, cha, start, and end parameters.
  • The sample data uses a simple synthetic waveform for demonstration.
Example: /fdsnws/dataselect/1/query?net=XX&sta=DEMO&cha=BHZ&start=2020-01-01T00:00:00&end=2020-01-01T00:00:10
